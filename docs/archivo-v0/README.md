# Archivo v0 — Análisis basado en una premisa equivocada

**No usar estos documentos como referencia de producto.**

Los dos archivos de esta carpeta se escribieron asumiendo que LEGADO era un
negocio de **producción de video física**: equipos de rodaje, cámaras reales,
ciclorama portátil, entrevistadores humanos yendo a casa del cliente.

Eso fue un malentendido. El proyecto real es una **web app donde todo se genera
con IA**, sin operación física de ningún tipo.

En consecuencia, quedan invalidados de estos documentos:
- toda la estructura de costos (COGS por rodaje, equipos, viáticos, capex de equipo)
- el modelo de "red de operadores licenciados"
- las proyecciones financieras completas del Año 0 al Año 5
- el análisis de estudio fijo vs. kit portátil

Lo que probablemente sigue siendo válido y vale la pena rescatar después:
- el panorama competitivo (Storyworth, Remento, HereAfter, tribute tech)
- el problema estructural de LTV / CAC en esta categoría
- el riesgo legal de clonación de voz y consentimiento
- los canales B2B2C (funerarias, comunidades de retiro, iglesias)
- la idea de la Cápsula como fuente de recurrencia
- el doblaje multilingüe en voz propia

Se conservan solo como registro. El análisis correcto se escribirá desde cero
una vez terminada la ronda de preguntas de requisitos.
